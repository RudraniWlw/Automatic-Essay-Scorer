#  Automatic Essay Scoring System

## Project Overview
An NLP-based system that automatically scores student essays using Machine Learning. Developed as an NLP microproject.

##  Objective
To build a system that can predict essay scores (1-12) with reasonable accuracy, reducing the manual effort required for grading.

## Technologies Used
- **Python 3.13** - Programming Language
- **Pandas** - Data Processing
- **Scikit-learn** - Machine Learning
- **Flask** - Web Framework
- **NLTK** - Text Processing
- **TF-IDF** - Feature Extraction
- **Linear Regression** - Prediction Model

##  Dataset
- **Source**: ASAP (Automated Student Assessment Prize)
- **Size**: 12,976 essays
- **Scores Range**: 1-12
- **Training Set**: 2,400 essays
- **Testing Set**: 600 essays
